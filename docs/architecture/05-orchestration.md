# 05 Agent 编排层（后端服务）

编排层由**平台后端代码仓库 `control-api`（Java Spring Boot）**承担，负责任务管理、瀑布状态机、排班权限与自我升级，是全系统的调度中枢。数据落地 MySQL（DDL/DML 在 `control-db`）。编排配置版本化于控制中心仓库 `orchestration/`。

## 技术选型

| 组件 | 选型 | 说明 |
|-----|------|------|
| 框架 | Java Spring Boot | Spring MVC + Spring Data JPA/MyBatis |
| 安全 | Spring Security | 角色/排班权限控制 |
| 调度 | Spring Scheduling / Quartz | 定时任务、Webhook 触发 |
| 异步 | Spring Async / 消息队列 | 任务派发、RAG 索引任务 |
| 存储 | MySQL | 元数据、工作记录、排班、审计 |

## 瀑布状态机

```
[需求分析] ──人工确认──→ [系统设计] ──人工确认──→ [编码实现] ──人工确认──→ [测试验证] ──人工确认──→ [交付]
    ↑                                                              ↓
    └──────────────────────── 变更回退（人工触发）───────────────────┘
```

| 阶段 | Agent 动作 | 人工审核点 | 输出物 |
|-----|-----------|-----------|--------|
| 需求分析 | 解析 PRD，检索 RAG，生成影响分析 | 确认需求理解正确 | 影响分析报告 |
| 系统设计 | 生成接口定义、数据库变更、时序图 | 架构师评审设计 | 设计文档（提交控制中心仓库 MR） |
| 编码实现 | 创建 feature 分支 + Worktree，编码、单元测试 | 代码 Diff 评审 | Commit + MR |
| 测试验证 | 集成测试、回归测试、静态检查 | 测试报告确认 | 测试报告 |
| 交付 | 合并到 dev/release，清理 Worktree | 最终确认 | 合并记录 |

### 阶段闸门（Approval Gate）

- 每阶段完成 → 生成报告 → Web 端推送审核通知 → 责任人审批 → 状态流转
- 审核拒绝 → Agent 接收反馈 → 修正 → 重新提交

## 任务管理

| 能力 | 说明 |
|-----|------|
| 任务分解 | 将需求/缺陷拆分为可执行子任务 |
| 上下文管理 | 跨阶段维护任务上下文（PRD、影响分析、设计决策） |
| 仓库分配 | 根据任务类型分配到目标代码仓库 |
| 分支/Worktree 生命周期 | 创建、回收、归档（配合代码仓库 OpenAPI） |

## 排班权限控制

- 按排班表约束 Agent 可执行的操作类别（只读/自动化/全权限）
- 操作日志绑定排班与责任人

## 自我升级

- 基于执行日志统计成功率，生成策略优化建议
- Prompt 版本化存 Git，升级即提 MR，需人工审批
- 升级配置双人审批 + 灰度发布
